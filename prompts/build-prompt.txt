REQUIRED ARCHITECTURE
Build the app with these major modules:

1. WEBHOOK INTAKE LAYER
- Accept TradingView webhook alerts by HTTP POST
- Support JSON payloads
- Validate payload structure strictly
- Reject malformed or incomplete payloads
- Store the raw alert
- Parse useful fields such as:
  - symbol
  - side or direction
  - timeframe
  - strategy/setup name
  - alert timestamp
  - optional entry / stop / target
  - source platform
  - metadata
- Support alert authentication or shared secret if configured
- Support idempotency protection and duplicate detection
- Log every received webhook with status

2. SIGNAL NORMALIZATION LAYER
- Normalize TradingView symbols to internal canonical symbols
- Provide MT5 symbol mapping support
- Handle broker suffix/prefix issues
- Mark alerts as:
  - valid
  - duplicate
  - stale
  - malformed
  - unmapped
  - waiting_for_validation
- Never allow unmapped or ambiguous symbols to proceed to execution approval

3. MT5 INTEGRATION LAYER

- order_calc_margin
- order_calc_profit if useful
- order_check

The wrapper must:
- fail safely
- return structured errors
- support demo and disconnected modes
- support mocking for tests
- never crash the app on MT5 unavailability
- clearly distinguish:
  - not connected
  - symbol missing
  - account restricted
  - order check failed
  - execution disabled

5. RISK ENGINE
This is one of the most important modules.
Implement strict risk logic including:
- default risk per trade: 0.5% equity
- hard max risk per trade: 1.0% equity
- daily loss limit
- weekly loss limit
- total open risk cap
- correlated exposure cap
- size rounding down only
- stop-first sizing
- no trade if minimum broker lot breaks risk rules
- no trade if stop is missing or invalid
- no trade if spread or cost drag is too high
- no trade if slippage allowance makes expected edge too weak
- no trade if margin becomes unsafe
- no trade if duplicate trade already exists
- no trade if daily or weekly lock is active

Position sizing must be derived from:
- account equity
- allowed risk amount
- stop-loss distance
- pip value estimate
- spread / commission / slippage allowance
- broker minimum lot
- broker lot step
- margin requirements
- open correlated exposure

Always round size down.
Never round up.
Always calculate and store the reason when rejecting a trade.

The engine must output one of:

The engine must be able to explain:

- what risk rule blocked it if blocked
