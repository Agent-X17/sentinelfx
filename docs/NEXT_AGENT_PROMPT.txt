PRODUCT PURPOSE

SentinelFX is a safety-first Forex research, signal-validation, position-sizing, paper-trading, and execution-decision control system for a Tanzanian trader with small starting capital.

Primary profiles:

- ACCOUNT_A = $50
- ACCOUNT_B = $100
- ACCOUNT_C = $150
- ACCOUNT_LIVE = initialized from MT5 equity when a validated MT5 connection is used

Priority order:

PRESERVE CAPITAL
LEARN
PROVE AN EDGE
BECOME CONSISTENT
COMPOUND
INCREASE CAPITAL
ONLY THEN CONSIDER LARGER INCOME

The system must prefer NO_TRADE over uncertain or unsafe approval. RiskManager has final veto.

CURRENT EXECUTION BOUNDARY

The default mode is SIMULATION.

Supported configuration modes:

- DISCONNECTED
- SIMULATION
- PAPER_TRADING
- LIVE_DISABLED
- LIVE_GATED, which is deliberately refused

Live execution is not implemented. Keep it that way during this review unless the user provides a separate explicit instruction after a complete security and operational design review.

Mandatory safety facts:

- LIVE_EXECUTION_ENABLED=true refuses startup.
- LIVE_GATED refuses startup.
- MT5Service.order_send() always returns LIVE_EXECUTION_NOT_IMPLEMENTED.
- There is no HTTP live-order endpoint.
- BUY or SELL in a bridge response means an approved simulation/paper candidate. It does not mean an order was sent.
- Client-supplied equity, risk budgets, proposed decisions, or position sizes cannot override stored account state or RiskManager.

RISK MODEL

For the three small fixed profiles:

- ACCOUNT_A: $0.25 max risk per trade, $1 daily loss cap, $2 weekly loss cap
- ACCOUNT_B: $0.50 max risk per trade, $2 daily loss cap, $4 weekly loss cap
- ACCOUNT_C: $0.75 max risk per trade, $3 daily loss cap, $6 weekly loss cap

ACCOUNT_LIVE uses conservative fractional limits based on its initialized MT5 equity.

The risk basis is min(current equity, starting equity), preventing profits from automatically increasing risk. Losing trades consume loss budgets; profits do not erase that consumption. Open risk is reserved immediately. The account allows one open position. Day boundaries use Africa/Dar_es_Salaam, and the week begins Monday.

Position sizing accounts for contract size, stop distance, spread, commission, slippage, swap, broker minimum/maximum/increment, free margin, projected margin level, remaining account risk, provider risk, correlation, and transaction-cost share. Position size always rounds down to the broker grid.
