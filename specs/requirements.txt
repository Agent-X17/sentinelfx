2. HARD RISK RULES
==================================================

Risk Engine has absolute final authority.

No AI component, technical strategy, macro model, signal provider, copied trader, manual operator, or execution service may override the Risk Engine.

Default conservative risk settings:

ACCOUNT_A = $50:
- maximum risk per trade: $0.25 to $0.50
- maximum daily loss: $1.00 to $1.50
- maximum weekly loss: $2.00 to $3.00
- target concurrent positions: 0 to 1

ACCOUNT_B = $100:
- maximum risk per trade: $0.50 to $1.00
- maximum daily loss: $2.00 to $3.00
- maximum weekly loss: $4.00 to $6.00
- target concurrent positions: usually 1, maximum 2 only if uncorrelated and risk remains within limits

ACCOUNT_C = $150:
- maximum risk per trade: $0.75 to $1.50
- maximum daily loss: $3.00 to $4.50
- maximum weekly loss: $6.00 to $9.00
- target concurrent positions: usually 1, maximum 2 only if uncorrelated and risk remains within limits

All risk limits must be configurable, but the initial defaults must remain conservative.

Mandatory hard rejects:
- If required lot size is below broker minimum lot size: NO TRADE
- If risk at broker minimum lot size exceeds risk budget: NO TRADE
- If spread plus commission consumes too much of allowed risk: NO TRADE
- If spread is abnormally wide: NO TRADE
- If a high-impact economic event is near: NO TRADE unless explicitly allowed by a conservative news-risk policy
- If daily loss cap is reached: NO TRADE for the rest of the day
- If weekly loss cap is reached: suspend trading until review
- If margin level would be unsafe: NO TRADE
- If signal is stale, duplicate, malformed, missing timestamp, unsupported symbol, or expired: NO TRADE
- If correlated exposure is excessive: NO TRADE
- If stop loss is missing: NO TRADE
- If risk/reward is below configured minimum: NO TRADE

Never force a trade to meet a daily profit target.

3. POSITION-SIZING ENGINE
==================================================

Build a PositionSizer that calculates every trade independently.

Inputs:
- account equity
- account currency
- currency pair
- direction
- entry price
- stop loss price
- take profit price
- stop-loss distance in pips
- pip value
- broker contract size
- broker minimum lot size
- lot-size increment
- leverage
- margin requirement
- spread
- commission
- swap estimate when applicable
- current open exposure
- correlated exposure
- risk limit per trade
- daily and weekly remaining risk allowance

Required formula:

position_size =
maximum_allowable_loss /
((stop_loss_pips × pip_value_per_lot) + estimated_transaction_cost)

Transaction cost must include:
- spread cost,
- commission,
- estimated slippage buffer,
- swap where relevant.

The actual final position size must be rounded DOWN to the broker’s allowed lot increment.

If rounding down causes an impractically small trade or if broker minimum volume causes excess risk, return:
NO TRADE

Never copy a provider’s position size directly.

Example:
If provider trades 1.00 lot, do NOT copy 1.00 lot.
Calculate follower size only from:
- my account equity,
- my stop distance,
- my permitted dollar loss,
- pip value,
- current exposure,
- broker constraints.

13. PROVIDER LEARNING RULES
==================================================

The system may learn provider weightings only from statistically meaningful evidence.

Examples:
- Provider A may perform better in trending conditions
- Provider B may perform poorly around high-impact news
- Provider C may perform better in EUR/USD than GBP/JPY

Requirements:
- do not infer skill from small samples
- display sample size
- use confidence intervals where practical
- separate in-sample from out-of-sample results
- never increase risk to recover losses
- never increase risk because a provider had recent losses
- never use loss-chasing or martingale logic
- always preserve maximum account-level risk caps
